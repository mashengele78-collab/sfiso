# CV QA checklist — blank template

> Save a completed customer-specific checklist outside Git. The repository may record only the yes/no summary fields in the non-personal order manifest.

## Truth and evidence — all must pass

- [ ] Names, contact details, links, dates, employers, institutions, qualifications, and locations match the confirmed source.
- [ ] No role, qualification, skill, responsibility, metric, award, reference, testimonial, or date was invented.
- [ ] Every number and outcome is customer-supplied or customer-confirmed.
- [ ] Ambiguities and contradictions were resolved with the customer, not guessed.
- [ ] Tailoring did not turn vacancy requirements into unsupported candidate claims.

## Writing

- [ ] The opening summary identifies the target and the candidate's real value without clichés.
- [ ] Bullets begin clearly, use consistent tense, and state evidence where available.
- [ ] Language is concise but still sounds like the candidate.
- [ ] Spelling and terminology fit the target country and role.
- [ ] No fabricated ATS score, shortlist promise, interview promise, or job guarantee appears.

## ATS and structure

- [ ] Standard section headings are used.
- [ ] Core information is text, not only icons, graphics, headers, or footers.
- [ ] Contact details are easy to find.
- [ ] Dates and headings follow one consistent format.
- [ ] Tables, columns, text boxes, decorative charts, and rating bars were avoided unless specifically justified and tested.
- [ ] Relevant vacancy language appears naturally and truthfully.

## File and visual checks

- [ ] DOCX and/or PDF output matches the order.
- [ ] Every output opens without an error.
- [ ] No clipping, overlap, orphan heading, bad page break, missing glyph, or blank page remains.
- [ ] PDF text can be selected/copied and follows a sensible reading order.
- [ ] Links work and point to the confirmed destinations.
- [ ] Filename and document metadata do not expose internal notes or another customer.

## Delivery gate

- [ ] Correct order and recipient were checked.
- [ ] Customer-specific comments and tracked changes were removed unless requested.
- [ ] Only approved final files are in the delivery package.
- [ ] A human reviewer approved delivery.
